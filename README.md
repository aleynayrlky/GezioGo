# Gezio

> Şehir seninle keşfedilir.

Gezio, kullanıcıların şehirleri kendi ilgi alanlarına, zamanlarına ve bütçelerine göre keşfetmelerini sağlayan yapay zekâ destekli mobil şehir ve turizm rehberi uygulamasıdır.

## İlk Hedef

İlk hedef, Samsun için tek şehirli, küçük ama çalışan bir iOS MVP geliştirmektir.

## İlk Platform

- iOS
- Swift
- SwiftUI
